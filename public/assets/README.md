# Resume Setup Instructions

## How to Add Your Resume

1. **Place your resume PDF file** in this folder (`public/assets/`)
2. **Name it:** `Sahil_Adhikari_Resume.pdf`
3. **Make sure it's a PDF format** for best compatibility

## Current Setup

The portfolio is configured to download a file named:
- `Sahil_Adhikari_Resume.pdf`

## File Path

The resume should be located at:
```
public/assets/Sahil_Adhikari_Resume.pdf
```

## How It Works

When visitors click the "Download Resume" buttons in your portfolio:
- **Hero Section**: Terminal-style download button
- **About Section**: Standard download button

Both buttons will trigger a download of your resume file.

## Supported Formats

- ✅ **PDF** (Recommended)
- ✅ **DOC/DOCX** (Will open in browser first)

## Notes

- The file will be accessible at: `https://yoursite.com/assets/Sahil_Adhikari_Resume.pdf`
- The `download` attribute ensures it downloads instead of opening in browser
- File size should be reasonable (< 5MB recommended)
